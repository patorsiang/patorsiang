## How I use GitHub

I keep my GitHub intentionally split into a few types of repos:

- **Showcase repos** — polished projects that represent my current direction
- **Learning archives** — coursework, practice, experiments, and older projects kept for history
- **Writeups and notes** — cybersecurity, engineering, AI, and product-thinking references
- **Private repos** — personal, sensitive, employer-adjacent, or unfinished ideas

Some older repositories are archived because they are no longer maintained, but I keep them visible when they are safe and useful as learning history.
